# Contributing

## Issues

Contributions are welcome from the community. Questions can be asked on the
[issues page](https://code.usgs.gov/great-lakes-science-center/wetlands/phragmites-adaptive-management-framework-model/-/issues). 
Before creating a new issue, please take a moment to search
and make sure a similar issue does not already exist. If one does exist, you
can comment (most simply even with just a :+1:) to show your support for that
issue.

Issues can include:
  
- Ideas to incorporate
- Problems encountered with the code
- Improvements on the user experience

## Merge Requests

This project is designed for a specific internal purpose, and our team currently 
has limited bandwidth to review or merge external contributions. Because of that, 
we may not be able to accept all pull requests. 

If you decide to open a merge request, please make it meaningful and 
well‑reasoned—clearly explain the problem it solves, why the change is 
necessary, and how it improves the project. High‑quality, thoughtfully scoped 
contributions are much more likely to be reviewed.

We appreciate your interest and support!
