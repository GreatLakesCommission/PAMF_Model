# TIMING-TEST-CASES  

:exclamation: This directory contains test cases specific to phase-date-agreement.R. It is not needed for regular running of the PAMF Model, and is only needed for debugging and testing purposes.  

> :warning: **Warning:** Don't make changes to the .csv versions of files in this folder! Instead, edit the .xlsx files and 
re-save to .csv  

## FILES

- manage-test.xlsx  
- manage-test.csv  
Test management reports exemplifying the cases defined in 
"timing test cases descriptions.xlsx".  
Assumes that application dates have already been merged into management reports
To make changes, edit the .xlsx version and save as .csv.  


- monissues-test.xlsv  
- monissues-test.csv  
Test monitor_issues lines exemplifying the cases defined in 
"timing test cases descriptions.xlsx".  

- monitor-test.xlsx  
- monitor-test.csv  
Test monitoring reports exemplifying the cases defined in 
"timing test cases descriptions.xlsx".  

- timing test cases descriptions.xlsx  
Test case definitions, expected outputs, date verified.
