# RUN-MODEL INITIAL-INPUTS  

Initial versions of inputs to the model (other than participant data). Generated
in 2018 and used in the 2018 model run. Subsequent model runs will use updated 
versions of these files, generated by a previous model run.  

> :memo: NOTE: The files indicated with a ":globe_with_meridians:" symbol and their associated metadata are present in the PAMF ScienceBase data release. These files are duplicated here as 'convenience copies' for running the model.  

## DIRECTORIES  

- :file_folder: [elicitation_data](src/run-model/initial-inputs/elicitation_data/)  
Files containing data from expert elicitation.  

## FILES

- **cost_rank_2017.csv** :globe_with_meridians:  
Previous PAMF Staff's cost ranking of management combinations. Generated prior to data collection (2017).  

- **cost_rank_2023.csv** :globe_with_meridians:  
PAMF Staff's cost ranking of management combinations updated based on PAMF data in 2023.  

-**management_combination_codes.csv**  
Management action codes used in (generate-policy-definitions.R)[./src/run-model/generators/generate-policy-definitions.R] to generate policy definitions.  

- **mean_sat_2018-08-16.csv** :globe_with_meridians:    
Mean satisfaction values for each state interpolated from elicitation data using
[interpolate-satisfaction.R](/src/run-model/generators/interpolate-satisfaction.R).   
These data were used in model runs from 2018-2022 and were eventually replaced 
with updated data in 2023 (see **satisfaction_by_cost_2023.csv**).  

- **pc_initial_matrix.csv** 
Initial partial controllability matrix. Assumes that that participants 
implement the guidance with probability of 1. Matrix form is used by the 
optimization.  

- **pc_initial_table.csv** 
Same as pc_initial_matrix but in dataframe form. Used for Bayesian updating.  

- **repaired_priors.csv** :globe_with_meridians:  
"trans_probs_EXPERT-2018-08-13.csv" put into the format that reports each state 
directly, and repaired so that all transition probabilities and concentrations
within each matrix row sum to 1.  
Generated using [repair-priors.R](/src/run-model/generators/repair-priors.R).    

- **reward_matrix-2018-08-16.csv** :globe_with_meridians:  
Matrix describing the satisfaction that experts expect from an MU in each state. 
NOTE: This matrix is populated using an interpolation that uses JAGS. Since JAGS 
is a heuristic, re-running the build_reward_matrix script could result in a file 
with slightly different results.  
DO NOT re-generate this initial version of the matrix unnecessarily.  

- **satisfaction_by_cost_2023.csv** :globe_with_meridians:  
Modeled satisfaction by cost ranking, where high cost ranking (16) = no cost, 
15 = lowest cost, and low cost ranking (1) = highest cost. Satisfaction for cost 
levels 2-14 are interpolated between those for cost levels 1 and 15. Data in 
this file were generated by 
[interpolate-satisfaction-2023.R](/src/run-model/generators/interpolate-satisfaction-2023.R), 
and starting in 2023 replace data from **mean_sat_2018-08-16.csv** (see above).  

- **trans_probs_EXPERT-2018-08-13.csv** 
Transition probabilities interpolated from expert elicitation.  
NOTE: The interpolation includes a bootstrapping step. Do not re-generate this matrix 
unless necessary; the transition probabilities will be slightly different than those found in this file.
See [interpolate-transitions.R](/src/run-model/generators/interpolate-transitions.R) for details.
