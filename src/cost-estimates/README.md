# cost-estimates  

Scripts and supporting functions that estimate the cost of the action described 
in management reports.  

## DIRECTORIES

- :file_folder: [test-cases](/src/cost-estimates/test-cases/)   
Test data for verifying specified behavior of cost calculations.  


## FILES

- [calculate-costs.R](/src/cost-estimates/calculate-costs.R)   
Estimates the cost of taking the action in each management report.  

- [cost-calculation-functions.R](/src/cost-estimates/cost-calculation-functions.R)   
Functions supporting cost calculations in cost-main.R. Defines cost calculations
for all PAMF management actions.  

- [cost-helper-functions.R](/src/cost-estimates/cost-helper-functions.R)  
Functions supporting cost data handling.
