# Test cases for model output comparisons

:exclamation: This folder contains data for testing the comparison function behavior. It is not needed for regular running of the PAMF Model, and is only needed for debugging and testing purposes.  

## FILES  

- **test-compare-guidance-1.csv**  
- **test-compare-guidance-2.csv**       
Two slightly different versions of example **guidance.csv** files output from the model for testing the comparison function.   

- **test-compare-partcontrol_matrices-1.csv**  
- **test-compare-partcontrol_matrices-2.csv**  
Two slightly different versions of example **partcontrol_matrices.csv** files output from the model for testing the comparison function.   

- **test-compare-policies-1.csv**             
- **test-compare-policies-2.csv**   
Two slightly different versions of example **policies.csv** files output from the model for testing the comparison function.  

- **test-compare-transition_matrices-1.csv**   
- **test-compare-transition_matrices-2.csv**  
Two slightly different versions of example **transition_matrices.csv** files output from the model for testing the comparison function.
