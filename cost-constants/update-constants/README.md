This folder contains raw data and sources used to estimate cost constants.  

## FILES  

- **cost_constant_raw_data_2018.csv**  
Raw data used to generated cost constants for 2018  

- **cost_constant_raw_data_2022.csv**    
Raw data used to generated cost constants for 2022  

- **cost_constant_raw_data_v2_2022.csv**    
This file contains the same data as **cost_constant_raw_data_2022.csv** but with additional rows for surfactants.  

- **cost_constant_raw_data_2023.csv**     
Raw data used to generated cost constants for 2023   
 
- **cost_constant_raw_data_2025.csv**     
Raw data used to generated cost constants for 2025   

- **update-cost-constants.R**    
R code to be used as needed to generate compiled cost constants from raw data
files
