This directory contains estimates of cost constants, e.g., gas and electricity
prices, herbicide prices, the cost of different categories of labor.

## FILES  

- **cost_constants2018.csv**  
Cost constants for products/services used in calculating costs associated with management actions, estimated in 2018 by PAMF staff.  

- **cost_constants2022.csv**  
Cost constants for products/services used in calculating costs associated with management actions, estimated in 2022 by PAMF staff.  

- **cost_constants_v2_2022.csv**  
Cost constants for products/services used in calculating costs associated with management actions, estimated in 2022 by PAMF staff.  
This file is the same as **cost_constants2022.csv** but has an additional row for surfactants.  

- **cost_constants_2023.csv**  
Cost constants for products/services used in calculating costs associated with management actions, estimated in 2023 by PAMF staff.  

- **cost_constants_2025.csv**  
Cost constants for products/services used in calculating costs associated with management actions, estimated in 2023 by PAMF staff. 

## FOLDERS  

- **update-constants**    
The "update-constants" folder contains a set of worksheets where you can fill in
updated cost values. Follow the instructions in the README file.  

- **test-cases**  
This directory contains cost constant test files. These files exist to test the
error checking code that is applied when the program reads the cost constant
data. To test, run the app, select each of these files in the menu and verify
that the behavior is as expected.
